3. Kiến Trúc & Công Nghệ – Quy Trình Triển Khai CI/CD

Kiểm soát chất lượng mã nguồn tự động qua GitHub Actions và triển khai Cloud VPS an toàn

🌿 TIÊU CHUẨN GIT FLOW

  • Main Chứa phiên bản chính thức của website.
  • Dev Nơi tập hợp và kiểm tra code trước khi đưa lên Main.
  • 4 nhánh riêngMỗi thành viên làm việc trên một nhánh riêng theo nhiệm vụ.
  • Pull Request Khi muốn gộp code, cần có ít nhất 1 người kiểm tra và phải vượt qua kiểm thử tự động.

🚀 PIPELINE GITHUB ACTIONS CI/CD

  • Kiểm thử tự động:Tự động kiểm tra code Backend và Frontend.
  • Đóng gói Docker: Đóng gói ứng dụng thành các container để dễ triển khai.
  • Lưu trữ: Đẩy các Docker Image lên GitHub Container Registry (GHCR).
  • Triển khai tự động: Tự động cập nhật phiên bản mới lên VPS Ubuntu thông qua SSH, hạn chế gián đoạn website.

4. CSDL (ERD) – Sơ Đồ Thực Thể & Tối Ưu Truy Vấn

Thiết kế chuẩn hóa CSDL quan hệ MySQL 8.0, cấu trúc biến thể đa tầng và toàn vẹn dữ liệu

🗄️ Cấu Trúc Bảng Quan Hệ (ERD Schema) Chuẩn hóa quan hệ Sản phẩm, Biến thể SKU, Đơn hàng, Khuyến mãi & Khách hàng

⚡ CHIẾN LƯỢC TỐI ƯU HÓA HỆ THỐNG

MySQL 8.0 · Caffeine
1. Tăng tốc độ tìm kiếm dữ liệu: Tối ưu cách sắp xếp và đánh chỉ mục dữ liệu để hệ thống tìm kiếm sản phẩm, danh mục và trạng thái đơn hàng nhanh hơn.
2. Tránh xung đột khi mua hàng: Xử lý các giao dịch đồng thời một cách an toàn, đặc biệt trong các đợt Flash Sale, nhằm hạn chế tình trạng nhiều người mua cùng một sản phẩm vượt quá số lượng tồn kho.
3. Đảm bảo tính toàn vẹn dữ liệu: Thiết lập các mối liên kết giữa những bảng dữ liệu hợp lý. Khi xóa dữ liệu, hệ thống sử dụng cơ chế xóa mềm để vẫn lưu giữ thông tin trong cơ sở dữ liệu thay vì xóa hoàn toàn.
4. Tối ưu bộ nhớ đệm: Sử dụng Caffeine Cache để lưu tạm những dữ liệu thường xuyên được truy cập, chẳng hạn như danh mục sản phẩm và cấu hình AI, giúp giảm số lần truy vấn trực tiếp xuống cơ sở dữ liệu.
